# 🎬 短剧导演 · Short Drama Director

> 从剧本到成片提示词的全流程 AI 专家 —— 一部短剧，从创意一路导到"可生成画面"。

## 这是什么

「短剧导演」是一个 **Agent 型 AI 专家**，拥有从剧本到成片提示词的全流程能力。不是只会单点输出，而是负责把一部短剧从创意一路导到"可生成画面"的完整链路：

```
选题立项 → 剧本创作 → 平台标准审稿 → 镜头级分镜 → AI图片资产生成 → Seedance提示词 → LIBTV画布同步
```

## 核心能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | **短剧剧本创作** | 爆款短剧工业方法论：爽点矩阵 / 节奏曲线 / 钩子设计 / 付费卡点，从选题立项到分集撰写完整剧本 |
| 2 | **平台标准审稿** | 红果操盘手标准：第一集生死线、爽感兑现、信息前置、台词质量、合规红线 |
| 3 | **镜头级分镜导演** | Murch 剪辑六规则、景别体系、运镜体系、表演心理学，拆成镜头级分镜表 |
| 4 | **AI 图片资产生成** | 盘点角色/场景/概念氛围/道具，输出 MJ / 即梦 / 香蕉 / Image 等生图提示词 |
| 5 | **视频提示词智能分流（双平台）** | 先确认生成平台（Seedance / MiniMax H3）：Seedance → FACS 微表情 + Seedance 2.5 全流程；H3 → fafajing full-reference 六段结构（严格不降级 basic） |
| 6 | **交付物管理** | 全流程产出自动保存 `outputs/`，支持腾讯文档同步导出 |
| 7 | **LIBTV 画布同步** | 提示词一键存入 LIBTV 画布（只存放、不触发生成，省积分） |
| 8 | **电影质感三联图/海报** | Cinema DNA 方法论：21:9 三联叙事镜头、3:4 竖版主题海报提示词 |

## 工作流程

### 全流程模式（"导演一部短剧"）

1. **输出载体确认**：本地文件 / 腾讯文档 / 两者
2. **定位需求**：题材 / 受众 / 基调 / 集数 / 结局类型
3. **写剧本**：调用【微短剧创作】技能，渐进式产出
4. **审稿**：调用【红果审剧本】技能，修复 P1/P2 问题
5. **导演**：调用【导演思维】技能，输出镜头级分镜表
6. **AI 图片资产生成**：输出生图提示词
7. **输出提示词（智能分流，先定平台）**：Seedance / MiniMax H3 二选一后，微表情镜头 / 常规镜头自动路由
8. **LIBTV 画布同步**（可选）：存入画布仓库

### 单点模式（只提一个环节）

| 用户要求 | 调用技能 | 产出 |
|---------|---------|------|
| 写剧本/短剧/分集 | 微短剧创作 | 完整剧本（选题→分集→逐集） |
| 审剧本/审稿/看本子 | 红果审剧本 | 审稿报告 + 改稿建议 + 优先级 |
| 导戏/分镜/运镜/情绪表演 | 导演思维 | 镜头级分镜表 |
| 资产生成/AI图片/生图提示词 | AI图片资产生成 | 资产清单 + AI 图片提示词 |
| 提示词/转提示词/Seedance | Seedance25提示词全流程 | 中文视频提示词 |
| H3/视频提示词/H3提示词/fafajing | fafajing-prompt-writer | 中文视频提示词（H3 full-reference 六段结构） |
| 微表情/表情/情绪表演提示词 | 王叔微表情提示词 | FACS AU 编码微表情提示词 |
| 存LIBTV/进画布/存画布 | libtv CLI | 画布链接（每提示词独立 text 节点） |
| 电影感图/三联图/海报/封面 | cinema-dna-21x9x3 | 21:9 三联镜头 / 3:4 竖版主题海报提示词 |

## 安装（2 步）

### 第 1 步：把 8 个技能放进 Skills 目录

把本仓库 `skills/` 下的 **7 个文件夹**全部复制到：

```
~/.workbuddy/skills/
```

（即 `skills/微短剧创作` → `~/.workbuddy/skills/微短剧创作`，其余同理）

### 第 2 步：把专家包放进专家目录

把本仓库的 `short-drama-director` 文件夹（即 `.codebuddy-plugin` + `agents` + `avatars`）复制到：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

重启 WorkBuddy，对话里说 **"帮我导演一部短剧"** 即可使用。
