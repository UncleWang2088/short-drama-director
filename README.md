## 这是什么

「短剧导演」是一个 **Agent 型 AI 专家**，拥有从剧本到成片提示词的全流程能力。不是只会单点输出，而是负责把一部短剧从创意一路导到"可生成画面"的完整链路：

```
选题立项 → 剧本创作 → 平台标准审稿 → 镜头级分镜 → AI图片资产生成 → 风格化单张 → 故事板9宫格 → Seedance提示词 → LIBTV画布同步
```

## 工作流程

### 全流程模式（"导演一部短剧"）

1. **输出载体确认**：本地文件 / 腾讯文档 / 两者
2. **定位需求**：题材 / 受众 / 基调 / 集数 / 结局类型
3. **写剧本**：调用【微短剧创作】技能，渐进式产出
4. **审稿**：调用【红果审剧本】技能，修复 P1/P2 问题
5. **导演**：调用【导演思维】技能，输出镜头级分镜表
6. **AI 图片资产生成**：输出生图提示词
7. **风格化单张（可选）**：调用【gaven-direct-image-prompts】，用户对关键场景/概念氛围图有风格要求时（王家卫/胶片感/黄金时刻）出风格化单张
8. **故事板 9 宫格**：调用【故事板9宫格】，分镜按 9 镜一组转 3×3 网格故事板图提示词（AI 视频参考图）
9. **输出提示词（智能分流，先定平台）**：Seedance / MiniMax H3 二选一后，常规镜头（CINEDANCE）/ 含表演镜头（ACTING）自动路由叠加
10. **LIBTV 画布同步**（可选）：存入画布仓库（含 9 宫格提示词）

## 安装（2 步）

### 第 1 步：把 10 个技能放进 Skills 目录

把本仓库 `skills/` 下的 **10 个文件夹**全部复制到：

```
~/.workbuddy/skills/
```

（即 `skills/微短剧创作` → `~/.workbuddy/skills/微短剧创作`，其余同理）

### 第 2 步：把专家包放进专家目录

把本仓库的 `short-drama-director` 文件夹（即 `.codebuddy-plugin` + `agents` + `avatars`）复制到：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

重启 WorkBuddy，对话里说 **"帮我导演一部短剧"** 即可使用。
