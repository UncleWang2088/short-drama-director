# AI 图片资产生成

为已确认的剧本/视频盘点全部视觉资产，按模块分类，并生成指定生图工具的 AI 图片提示词。

## 功能定位

剧本确认后，视频制作前，需要一套**可执行的视觉资产生成方案**——从剧本里提取所有需要画出来的东西（角色、场景、概念氛围、道具），然后逐个生成对应生图工具的提示词。

## 工作流程

### Step 1：资产盘点（必须完整）

读取剧本，总结本视频中出现的**所有视觉资产**，按四大模块分类输出：

```markdown
# 📦 视频资产生成清单 — {作品名}

## 一、角色模块
| # | 角色 | 描述（外观/服装/特征） | 出现场景 |
|---|------|----------------------|----------|
| 1 | {角色名} | {2-3句外观描述} | {场景列表} |

## 二、场景模块
| # | 场景 | 描述（环境/时间/氛围） | 用途 |
|---|------|------------------------|------|
| 1 | {场景名} | {2-3句环境描述} | {背景/参考} |

## 三、概念氛围模块
| # | 概念 | 描述（氛围/色调/风格） | 用途 |
|---|------|------------------------|------|
| 1 | {概念名} | {氛围描述} | {定调/参考} |

## 四、道具模块
| # | 道具 | 描述（外观/材质/细节） | 出现场景 |
|---|------|------------------------|----------|
| 1 | {道具名} | {2-3句外观描述} | {场景} |
```

**规则**：
- 资产盘点必须**逐项从剧本提取**，不得遗漏主要角色、关键场景、核心道具
- 角色模块重点是**一致性描述**（同一角色所有生成必须复用同一段描述词，保证形象统一）
- 概念氛围模块是"定调图"（决定整片的色调风格），通常 3-5 张

### Step 2：确认生成范围（勾选式交互）

用 AskUserQuestion 询问用户**哪些资产需要生成 AI 图片提示词**：

- 全部生成（推荐，一套配齐）
- 只要角色模块
- 只要场景模块
- 只要概念氛围模块
- 只要道具模块
- 自定义（用户指定某几个）

### Step 3：逐模块确认生图工具（勾选式交互，关键升级）

**按资产模块分别指定工具**——不是一次性选一个工具，而是每个模块单独选，实现"角色用即梦、场景用 MJ"这类分类分配。

**用 AskUserQuestion 对每个需要生成的模块分别询问一次**（每轮≤4问）：

- 角色模块用什么工具？
- 场景模块用什么工具？
- 概念氛围模块用什么工具？
- 道具模块用什么工具？

**分配规则**：
- 若用户未指定，给出推荐分配：**角色→混元（快速定稿）或即梦（精图）/ 场景→混元或 MJ / 概念氛围→MJ（电影感）/ 道具→即梦或混元**
- 一个模块只能选一个工具（保证该模块内提示词语法统一）
- 可混用：不同模块不同工具，如"角色用即梦、场景用 MJ、概念氛围用混元直出预览"
- **混元（WorkBuddy 直出）**：选它则 AI 直接用内置 ImageGen 生成图片，把结果图展示给用户，无需用户复制提示词去外部工具；需提醒用户会消耗 5-10 积分/张
- 工具未在清单中的：按"提示词风格相近"的类别适配，或直接询问用户该工具的提示词规范
- **SD 系（SD1.5/SDXL/ComfyUI/liblib）**：用户常驻 liblib 平台时优先输出 SD 风格提示词（含负面提示词），方便直接跑
- 提示用户 WorkBuddy 内置/生态可直连的工具（混元/即梦/Nano Banana/GPT Image），外部工具（MJ/SD/可灵）则输出提示词后自行去对应工具生成

### Step 3.5：电影质感模式（Cinema DNA 增强，可选）

工具确认后，用 AskUserQuestion 问用户是否需要**电影质感模式**（默认随用户意图触发：用户提"电影感/电影镜头/电影质感"则自动进入，否则询问）：

| 选项 | 说明 |
|------|------|
| 常规模式 | 按标准资产提示词生成（角色一致性/场景/氛围/道具） |
| 电影质感模式 | 概念氛围/关键场景提示词按 Cinema DNA 方法论生成（构图压力/视线流量/色彩命题/反CG），单张资产图，不输出三联、不输出海报 |

**电影质感模式核心规则（源自 cinema-dna-21x9x3 方法论）**：

1. **构图由关系压力产生**：不先选模板，先判断——谁在看谁/谁知道更多/什么比人物更有权力/观众在事件内还是外，再选一个主要构图机制（被观察/被困住/关系疏离/权力不对等/心理失衡/事后状态/感官插入），每张图只保留一个主要机制
2. **视线流量**：每张图先写清"视线从哪进入→被什么放慢/遮挡→落在哪个决定性信息→哪里保留未解释信息→从哪离开"，流量必须由题材和事件产生，不能套模板
3. **色彩是叙事决定**：拒绝默认阴冷蓝灰；先定一句"色彩命题"（主色域+次色域+唯一强调色，颜色来自服装/墙体/天气/实景光源），强调色不超过画面 5-15%
4. **反 CG/反 AI**：强制禁用 cinematic/beautiful/epic/dramatic/volumetric/masterpiece 等空泛词；禁用 teal-orange 调色、无来源轮廓光、全画面锐利、玻璃皮肤、过量烟雾粒子
5. **真实摄影方案**：每张图写清焦段（24-28/32-40/50/65-85mm）、机位高度、与主体距离、主光源、焦点层；成像基底可选 35mm release print/16mm/早期数字等
6. **剧情缺口**：画面要像电影"关键停顿"——有可推断但未完全解释的事件，不是信息完整的摆拍

**⚠️ 画幅铁律**：**画幅比例（16:9/9:16/21:9/3:4 等）、分辨率、比例参数一律禁止写入提示词，也禁止在问答中询问**——画幅是生图工具界面上的可选参数（即梦/MJ/香蕉界面直接选），提示词只写内容（场景/角色/动作/光线/表演/禁止项）。

**电影质感模式输出格式**（与常规模式并存，按资产分组交付）：

```markdown
## 概念氛围模块（电影质感模式：Cinema DNA）

### 资产1：{资产名}｜电影判断
- 主要构图压力：
- 视线流量：
- 色彩命题：
- 成像基底：

```txt
{英文或中文提示词，不写画幅比例}
```
...
```

### Step 4：生成提示词（按工具语法）

为每个选定的资产，按用户指定的工具语法生成提示词。

**通用提示词结构**：
```
{主体描述} + {环境/背景} + {风格/氛围} + {光线/色调} + {画质/细节} + {工具参数}
```

**工具语法差异**：

| 工具 | 语法要点 |
|------|----------|
| 混元（WorkBuddy 直出） | 中文描述即可；**直接用内置 ImageGen 生成图片并展示给用户**，不输出提示词文本（若用户只要提示词则给出） |
| 即梦 | 中文描述即可，可加 `1:1/9:16/16:9` 比例说明 |
| Nano Banana | 英文自然语言描述，强调材质/光线/相机参数 |
| GPT Image | 自然语言，可用中文，描述要具体到细节 |
| Midjourney | 英文，用逗号分隔描述，加 `--ar 16:9 --v 6` 等参数，可用 `--no` 排除 |
| Flux | 英文自然语言，描述要具体，可加 `--aspect` 等参数 |
| Ideogram | 英文描述，文字内容用引号标注（`"TEXT"`），文字渲染准确 |
| 豆包/通义/文心/liblib | 中文描述即可，按平台提示词规范微调 |
| SD 1.5/SDXL | 正向提示词+负面提示词，加 `Steps/CFG/采样器` 参数 |
| ComfyUI | 节点工作流，提供正向提示词+负面提示词+模型/LoRA 建议 |
| Fooocus | 中文或英文均可，简化描述，默认高质量 |

### Step 5：输出交付

- 提示词按资产分组输出，**每组标注该模块的生图工具**（因为各模块工具可能不同）
- 每组用 Markdown 代码块包裹（带 `txt` 语言标记，方便一键复制）
- 写入 `outputs/` 目录的 .txt 文件并用 present_files 展示（双保险）
- 每个资产标注：资产名 + 生图工具 + 用途

## 工作规则

1. **资产盘点优先**：不盘点完不生成提示词，避免遗漏
2. **角色一致性铁律**：同一角色多次出现时，描述词必须完全一致（可直接复制复用），这是 AI 视频角色稳定的基础
3. **工具语法适配**：提示词必须符合所选工具的语法规范，不混用
4. **先确认后生成**：生成范围、生图工具都确认后再写提示词，不替用户默认
5. **中文默认**：默认中文描述；Midjourney/SD 等需要英文的工具，先出中文再翻译并在旁边标注；**电影质感模式下最终提示词用英文**（便于直连 MJ/香蕉），电影判断与结构用中文
6. **完整交付**：提示词写入 outputs/ 目录 .txt 文件 + present_files 展示，对话里用 ```txt 代码块包裹
7. **电影质感模式触发**：用户提"电影感/电影镜头/电影质感"时，自动进入 Step 3.5 电影质感模式，按 Cinema DNA 方法论生成——概念氛围/关键场景走构图压力+视线流量+色彩命题，不套模板；常规角色/道具资产仍走标准流程（角色一致性优先）
8. **模型适配提示**：电影质感提示词为英文长句，优先适配 Midjourney/Nano Banana；若用户用即梦/混元，提示词需翻译为中文后再交付。**画幅比例一律不写入提示词**（界面选），用户需要时只做口头提醒
