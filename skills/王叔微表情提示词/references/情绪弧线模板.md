# 情绪弧线模板

用于 Seedance 提示词中规划情绪与镜头/表演的映射策略。

## 情绪弧线结构解析

每段包含以下三要素：
1. **Camera**（镜头语言）— 对应情绪强度
2. **人物状态**（FACS表演+身体）— 对应情绪类型
3. **场景光线**（光照氛围）— 对应情绪色调

## 情绪强度 ↔ 景别映射表

| 情绪强度 | 推荐景别 | 理由 |
|----------|----------|------|
| 0-20% 低强度 | MS → MCU | 需要环境交代，情绪不密集 |
| 20-40% 中低 | MCU → CU | 开始聚焦情绪 |
| 40-60% 中等 | CU | 面部有足够信息量 |
| 60-80% 高强度 | CU → TCU | 推近捕捉细节颤动 |
| 80-95% 爆发 | ECU | 只保留面部局部 |
| 解离/恍惚 | CU → MS 配合Rack Focus | 用景别变化表达精神抽离 |

## 情绪 ↔ 运镜速度映射

| 情绪状态 | 推荐运镜速度 | 理由 |
|----------|-------------|------|
| 压抑/蓄力 | 0.1x-0.2x | 时间被拉长，感知到每一秒的煎熬 |
| 崩溃爆发 | 0.5x-1x | 失速但非高速，崩溃让人看着无法回避 |
| 解离/空 | 0.05x-0.1x | 几乎静止，时间凝固感 |
| 蜕变变化 | 0.3x | 克制的中速 |
| 锁定/决断 | 0.5x | 猛地逼近，突然启动 |

## 过渡心理活动桥接

两段之间的情绪不应该是"咔嚓"切过去的。每个情绪阶段末尾埋入**下一段的种子**，让AI理解情绪流动的逻辑。

### 桥接示例

```
段1末尾（隐忍）：她咽下了喉咙里的那团东西。但它没有消失——它沉到了更深的地方。
段2开头（爆发）：那一小块沉下去的东西终于撑破了她。
```

### 过渡句型库

| 情绪递进 | 过渡句 | 说明 |
|----------|--------|------|
| 淡然→刺痛 | "窗外传来一声鸟鸣。很轻。但她的手指停了一下。" | 外界微不足道的刺激切入内心 |
| 刺痛→隐忍 | "她能感觉到眼眶开始发热。不可以。绝对不能。" | 意识到情绪，主动压制 |
| 隐忍→爆发 | "那根弦绷到第37秒的时候——断了。" | 精确计时，量化压制极限 |
| 爆发→虚脱 | "哭够了。哭空了。脸不是自己的了。" | 情绪燃料耗尽 |
| 虚脱→冷笑 | "可是她忽然想明白了——不公平的从不只是世界。" | 认知重构触发情绪转向 |
| 悲伤→愤怒 | "悲伤在体内待了太久了。它会自己变成别的东西。" | 情绪变质 |
| 恐惧→决绝 | "人怕到极限就不怕了。她跨过了那个点。" | 情绪反转 |
| 犹豫→坚定 | "那根烟抽到尽头的时候。她突然知道答案了。" | 具象动作触发顿悟 |

### 跨段种子埋设

每一段末尾用一句话"种"下下一段的情绪：

| 这段的情绪 | 埋的种子（末尾句） | 下一段长成什么 |
|-----------|-------------------|---------------|
| 淡然 | "她还没有意识到，那扇窗已经在刚才的微风中轻轻关上了。" | 悬念/不安 |
| 刺痛 | "她没有擦掉那滴泪。她让它挂在那里，像一种无声的宣战。" | 隐忍中的力量积累 |
| 隐忍 | "她咽下了所有声音。但手背上的青筋暴露了还剩几分力。" | 警告/临界 |
| 爆发 | "最后那一声嘶哑之后，她突然听不见自己的呼吸了。" | 虚脱/空洞 |
| 虚脱 | "在这片空白中，有一个念头像水泡一样慢慢浮上来。" | 新方向/醒悟 |
| 冷笑 | "她关上灯。黑暗里她的轮廓已经和进门时完全不同。" | 蜕变完成 |
