## AU 组合 = 情绪表达式

### 悲伤
- **轻微悲伤**: AU1 + AU4 + AU15（眉内上抬+皱眉+嘴角下）
  - 数值范围: AU1@20-40%, AU4@15-30%, AU15@1-2mm
- **中度悲伤**: AU1 + AU4 + AU15 + AU17（加下唇上推）
  - 数值范围: AU1@40-60%, AU4@30-50%, AU15@2-3mm, AU17@30-50%
- **崩溃式悲伤**: AU1+AU4+AU6+AU15+AU17+AU24（加眼轮匝肌收紧+嘴唇压白）
  - 数值范围: AU1@60-80%, AU4@50-80%, AU6@70-100%, AU15@3-4mm, AU17@50-80%, AU24@80-100%
- **特大悲伤/嚎哭**: AU1+AU4+AU6+AU7+AU9+AU15+AU16+AU27
  - 特征: 眉毛内上抬+皱眉+眼轮匝肌眶部+睑部全收缩+皱鼻+嘴唇下拉+嘴巴大张

### 恐惧
- **轻微恐惧**: AU1+AU2+AU5+AU20+AU26（眉上抬+上睑提+嘴角侧拉+张嘴）
  - 数值范围: AU1+AU2@30-50%, AU5@40-60%, AU20@20-40%
- **强烈恐惧**: AU1+AU2+AU4+AU5+AU7+AU20+AU25+AU26
  - 数值范围: AU1+AU2@50-80%, AU4@30-50%, AU5@60-90%, AU7@50-80%
- **僵直恐惧**: AU4+AU5+AU7+AU23（瞪眼+眯眼+嘴紧闭，冻结反应）
  - 数值范围: AU4@40-60%, AU5@90-100%, AU7@60-80%, AU23@80-100%

### 愤怒
- **蓄压愤怒**: AU4+AU7+AU23+AU24（皱眉+眯眼+嘴紧闭+压白）
  - 数值范围: AU4@40-70%, AU7@50-80%, AU23@60-90%, AU24@70-100%
- **爆发愤怒**: AU4+AU5+AU7+AU9+AU16+AU27（瞪眼+皱鼻+张嘴）
  - 数值范围: AU4@60-100%, AU5@40-60%, AU7@70-100%, AU9@30-50%
- **冷笑愤怒**: AU4+AU12+AU14（皱眉+假笑+颊肌侧拉）
  - 数值范围: AU4@30-50%, AU12@20-40%, AU14@40-60%

### 惊讶
- **轻微惊讶**: AU1+AU2+AU5+AU26
  - 数值范围: AU1+AU2@20-40%, AU5@30-50%, AU26@20-40%
- **强烈惊讶**: AU1+AU2+AU5+AU27+AU38（嘴大张+鼻孔扩）

### 厌恶
- **轻微厌恶**: AU9+AU10+AU15
  - 数值范围: AU9@20-40%, AU10@20-40%, AU15@1-2mm
- **强烈厌恶**: AU4+AU7+AU9+AU10+AU15+AU38

### 解离/麻木
- AU1+AU4（悲伤眉但无下脸反应）+ AU41（上睑下垂）+ AU25（嘴唇微张无表情）
  - 数值特征: 眉毛悲伤但嘴部松弛不匹配，呼吸浅

### 窃喜/猎食
- AU12（单侧上升）+ AU14（颊肌侧拉）+ AU4（轻微皱眉）
  - 特征: 不对称冷笑，嘴微笑但眼无笑

## 肌肉收缩状态数值规范

描述肌肉收缩时使用以下数值维度：

| 属性 | 范围 | 示例 |
|------|------|------|
| 收缩率 | 0-100% | orbicularis oris at 80% contraction |
| 位移 | mm | depressor anguli oris pulls mouth corners down 2mm |
| 频率 | Hz | orbicularis oculi tremor initiates at 3Hz |
| 幅度 | 轻/中/强 | 或数值化如 tongue protrusion 3mm |
| 持续时间 | s | hold for 0.3s before collapsing |
| 速度 | 急/缓 | stutter-open in 2mm increments |

## 掩盖/压制/伪装表情模式

情感压抑不是"没有表情"，而是**对抗肌肉群和泄漏肌肉群同时激活**产生的张力场。

### 压制经典模式

| 模式 | AU组合 | 描述 | 视觉效果 |
|------|--------|------|----------|
| 唇白压制 | AU32@70%+AU24@80%+AU23@60% | 咬紧牙关+压白嘴唇+紧闭 | 嘴周发白，下颌线棱角分明 |
| 屏息压制 | AU43@50%+呼吸停滞2-3s+AU4@40% | 闭眼+屏息+皱眉收紧 | 整个上半身静止，充满爆发前张力 |
| 咬肉压制 | AU32@90%+AU24@95%+AU17@60% | 极度咬紧+嘴唇内外翻+下唇顶推 | 嘴部呈不自然收紧，下巴有橘皮样褶皱 |
| 喉锁压制 | 喉结上下滚动+胸锁乳突肌绷紧+AU4@50% | 吞咽动作压住涌上的情绪 | 颈部侧面肌肉条棱清晰可见 |
| 握拳压制 | 手指逐根收拢+掌骨突出+指节泛白 | 手动代替面部承受压力 | 从指尖开始，每根手指依次蜷曲 |
| 视线冻结 | 瞳孔锁定+AU4@30%+AU41@20% | 盯着某处不敢移开，怕一移就破 | 眼神僵直，眨眼频率<3次/10s |
| 伪装微笑 | AU12@30-50%+AU6@0-10%+AU14@40% | 嘴角抬但眼不笑，颊肌侧拉收窄嘴 | 嘴在笑脸上在哭，不对称 |

### 压制失败递进时序

压制和泄漏之间有时序关系，以下为经典递进路径：

```
内心波澜 →
  ① 喉结吞咽（第一道防线，0.1-0.3s） →
  ② 咬肌咬紧+嘴唇压白（第二道防线，0.3-0.8s） →
  ③ 鼻翼轻微开合（呼吸开始不稳，0.5-1.0s） →
  ④ 眼轮匝肌睑部收紧眯眼（视觉隔离，0.8-1.5s） →
  ⑤ 嘴角微不可控的下拉/颤抖（泄漏开始，1.0-2.0s） →
  ⑥ 眼泪/声音/完全失控（防线崩溃，2.0s+）
```

每个阶段对应不同的压制深度。提示词应明确标记当前处于哪个阶段。

### 压制强度与AU数值映射

| 压制等级 | 状态描述 | AU特征数值 |
|----------|----------|-----------|
| 等级0 未触发 | 内心未动 | AU4<5%, AU24<10% |
| 等级1 警觉 | 刚被触动但未确认 | AU4@10-20%, 喉结吞咽1次 |
| 等级2 压制启动 | 确认情绪，开始对抗 | AU32@40-60%, AU24@40-60%, 屏息 |
| 等级3 压制峰值 | 全力对抗，接近极限 | AU32@70-90%, AU24@70-90%, 手指蜷曲 |
| 等级4 微泄漏 | 压不住了，细小信号漏出 | AU6@20-40%颤抖, AU15@10-20%下拉 |
| 等级5 临界 | 最后一秒，随时崩 | AU组合复合对抗，全身静止/绷紧 |
| 等级6 突破 | 防线崩溃 | AU全面爆发，眼泪/声音/身体 |

| 状态 | 特征 |
